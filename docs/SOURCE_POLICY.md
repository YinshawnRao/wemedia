# Source Policy

This project can use YouTube and web video as source material only when the use is legally and ethically supportable.

## Current Project Context

The current music roundup workflow is for personal local testing and iteration, not commercial publishing. This means `rights_review` material can be used for local preview demos when the source and time range are recorded, but it must not be described as commercially cleared.

The project still does not support bypassing DRM, paid access, member-only restrictions, private videos, or platform access controls.

## Allowed by Default

- User-owned footage
- Footage the user explicitly has permission to use
- Creative Commons or public-domain footage where terms are recorded
- Official press kits and media assets that permit the intended use
- Small excerpts for commentary, criticism, education, or news analysis after a rights review

## Needs Review

- Commercial videos from creators or brands
- Music videos, movie clips, sports broadcasts, TV segments
- Long excerpts where the source is the main value of the final video
- Any clip where the license or platform terms are unclear

## Not Allowed

- DRM circumvention
- Downloading from private, paid, or access-restricted sources without authorization
- Misleading edits that change the meaning of a quoted speaker
- Removing attribution or source context when it is needed for clarity

## Attribution Minimum

For every used clip, keep:

- source URL
- title
- channel or publisher
- publication date if available
- download date
- exact time range
- rights status
- final video where it appears
