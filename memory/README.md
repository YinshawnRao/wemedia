# Project Memory

这个目录保存跨对话需要继承的关键上下文。它不是临时区，不应该随手清空。

推荐每次重要推进后更新：

- `project-state.md`：当前项目状态、下一步、正在跑的实验。
- `video-production-contract.md`：跨对话必须继承的视频制作默认规则、目录边界、渲染与 QA 契约。
- `decisions.md`：已经确认过的流程、目录、工具和约束。
- `learnings.md`：实验后沉淀的经验，尤其是失败原因、有效模板、风险点。
- `open-questions.md`：还没确认的问题。

原则：

- `sandbox/` 里的产物可以删；`memory/` 里的结论要保留。
- 每条结论尽量写日期、实验编号和为什么这么判断。
- 不把大段素材、转写、下载日志塞进这里，只记录可复用信息。
- 新对话制作视频前必须先读 `video-production-contract.md`，再读当前项目状态和相关实验记录。
