# Experiment 001

## Direction

趣味科普短视频。

## Goal

跑通第一条最小短视频生产链路，而不是追求最终发布质量。

成功标准：

- 选出一个 30-45 秒可讲完的题。
- 找到 2-4 个相对安全的素材来源。
- 用测试模式下载最小切片。
- 写出剪辑 brief。
- 用 HyperFrames 做出可预览 demo。
- 完成一次 QA 复盘。

## Recommended Topic

太空里的火焰为什么是圆的？

选择理由：

- 画面反直觉，适合前 3 秒 hook。
- 科学解释简单：地球上热空气上升，微重力中对流弱，火焰更接近球形。
- NASA 有公开说明和视觉素材，适合第一轮降低版权风险。
- 30-45 秒足够讲清楚。
