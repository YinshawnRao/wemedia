# Editing Brief Draft

Status: draft, before media download.

## Slug

`experiment-001`

## Working Title

太空里的火焰为什么会变圆？

## Audience

泛知识短视频观众，适合对科学冷知识、太空、反常识现象感兴趣的人。

## Platform and Format

- Format: 9:16 vertical
- Target duration: 30-45 seconds
- Style: 清晰、快速、强字幕、轻包装

## Hook

你以为火焰天生就是尖的？到太空里，它会变成一个蓝色小球。

## Beat Outline

```text
0-3s    Hook + 对比画面
3-10s   NASA 微重力火焰画面
10-20s  用一句话解释地球火焰为什么尖：热空气往上跑
20-30s  解释太空火焰为什么圆：没有明显上下方向，氧气主要靠扩散
30-40s  点题：NASA 研究它是为了太空舱防火和燃烧安全
```

## Caption Style

- 中文大字幕，短句，最多两行。
- 关键词用 warm yellow 或 red-orange 强调。
- 画面角落保留 source label。

## Voiceover

第一轮建议先用字幕，不做旁白，降低变量。

## Risks

- 不能暗示普通人在密闭环境里做危险火焰实验。
- 使用 NASA 素材时保留来源标记。
- 如果 YouTube 下载失败，先用 NASA 图片素材和简单动效完成 fallback demo。
