# Experiments

这个目录保存每一轮内容实验的过程档案。它和 `sandbox/` 的区别：

- `experiments/`：保留计划、选题、素材候选、brief、复盘和结论。
- `sandbox/`：保存临时下载、临时剪辑、测试导出，可以清理。

推荐结构：

```text
experiments/
  experiment-001/
    README.md
    idea_pool.md
    source_candidates.md
    editing_brief.md
    qa_retrospective.md
    run_log.md
```

实验编号持续递增，不按主题重置。
